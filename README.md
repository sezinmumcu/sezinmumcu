I studied psychology, which means I've always been more interested in *why* a number looks the way it does than in the number itself. That skepticism turned into a career in analytics; I now work in the Country Business Navigation team at IKEA Netherlands, where I build the analyses and dashboards that help the organization understand commercial performance across stores.

I care about getting the analysis right and about making it look good enough that the right person actually reads it.

## 📂 Featured Projects

**[🕐 Time Series Pattern Analysis](https://github.com/sezinmumcu/TimeSeriesPatternAnalysis)** — Custom visualization techniques (Line Tail Animation, Flow Field Analysis) to surface patterns in sequential behavioral data that standard charts miss. Built at Leiden University's CodeLAB.

**[📰 BBC News Analysis](https://github.com/sezinmumcu/BBC-News-Analysis)** — Text analysis pipeline across 500 articles: statistical profiling, BART-based summarization, and word cloud visualizations by category.

**[🏨 Hotel Review Analysis](https://github.com/sezinmumcu/ML-Projects)** — Classification, regression, and clustering on 515k European hotel reviews. 74% classification accuracy; the interesting part was figuring out which features actually mattered.

**[🎵 Spotify 2023](https://github.com/sezinmumcu/Spotify2023)** — Gradient Boosting model predicting streaming performance from audio features, with an interactive dashboard for exploring what separates hits from the rest.
